Selected work / continuous improvement

Three problems. Three targeted improvements.

Requirement decomposition, sprint task management, and change management each addressed a different failure mode in engineering execution.

01 / REQUIREMENT DECOMPOSITION

Problem

PRD and system requirements did not always reveal everything each subsystem still had to satisfy.

WHAT CHANGED Engineers had to reason from components → subsystems → system, then convert DFMEA findings into explicit subsystem requirements.
02 / SPRINT TASK MANAGEMENT

Problem

Unplanned requests could change engineering focus faster than project priorities did.

COMBINED EFFECT — REQUIREMENT DECOMPOSITION + SPRINT EXECUTION < 5 months One cross-functional program completed in under five months against an initial six-month estimate.
03 / CHANGE MANAGEMENT

Problem

The same high-level ECN process behaved differently by site — and factory changes were not always verifiable from Design.

WHAT CHANGED Standardized approval roles across sites, then closed the ECN loop by requiring the updated factory BOM to return to Design for verification.
