# Ben Lin — Personal Engineering Portfolio

Static GitHub Pages site for Ben Lin.

## Pages

- `index.html` — portfolio homepage
- `ai-engineering.html` — Universe / AI-enabled engineering case study
- `product-engineering.html` — product engineering case study
- `engineering-leadership.html` — engineering leadership case study
- `404.html` — custom error page

## Site structure

The site is intentionally built with plain HTML, CSS, and a small amount of JavaScript so it remains easy to host, inspect, and maintain on GitHub Pages.

## Development

Open `index.html` locally or serve the repository with any static file server.
