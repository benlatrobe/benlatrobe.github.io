01 / THE IDEA

Why I started it

AI can help with engineering, but engineering is more than generating an answer.

In my day-to-day work, I began exploring AI-assisted tools for requirements, technical research, design artifacts, calculations, and validation within an existing engineering and PLM environment.

Universe is my personal extension of that work: a side project exploring what an AI-assisted development environment could look like when agents can work with engineering state and engineering tools—not just a conversation.

02 / ARCHITECTURE

Connect reasoning to engineering state

Separate the responsibilities.

Universe separates AI reasoning, engineering state, execution, domain logic, external software, and engineer review.

AGENT Understand / propose / coordinate uses context and plans work, but does not own engineering authority
requests ↓
CORE Engineering state + revisions identity, immutable revisions, evidence, lifecycle policy
RUNTIME Execution + recovery tasks, checkpoints, journals, receipts
DOMAINS Engineering meaning schemas, calculations, rules, geometry, validators
engineering state + evidence ↑    external tools ↓
ADAPTERS Engineering software CAD, formats, solvers, source acquisition, fidelity checks
WORKBENCH Engineer review requirements, models, calculations, evidence, changes, open issues
Canonical Engineering Models (CEMs)

A CEM is a structured, versioned representation of engineering entities, relationships, properties, and evidence. It gives agents, domain tools, and engineers a shared design state while keeping revisions and evidence explicit.

03 / WHAT I HAVE BUILT

From concept to working pieces

Architecture matters more when there is something behind it.

ENGINEERING TOOLS

Domain calculations + engineering software

Implemented work includes electrical and power calculations, component screening, system interfaces, geometry, bounded thermal and scenario studies, validation, and FreeCAD / OCCT integration.

AGENT WORKFLOW

AI proposes; tools establish evidence

The agent interprets context and proposes bounded work. The host controls execution, engineering tools perform checks, and results stay tied to their inputs and evidence.

WORKBENCH

Review the engineering work, not just the conversation

A React / TypeScript review environment brings together requirements, models, calculations, evidence, proposed changes, open issues, and 3D visualization.

Implementation stack

Rust supports Core and Runtime. Python connects agents, domain tools, and engineering software. Workbench uses TypeScript / React and Three.js.

Component selection

A shortlist is a proposal—not a design decision.

One implemented workflow connects project requirements, candidate discovery, source evidence, domain screening, and engineer review.

Current status

Universe is an active personal side project, not a finished or production-qualified platform. It gives me a practical way to explore how AI agents, engineering tools, structured models, evidence, and human review can work together in product development.
